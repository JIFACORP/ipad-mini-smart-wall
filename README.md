# Smart Wall · iPad Mini 2

Pantalla inteligente de pared diseñada específicamente para **iPad Mini 2 (iOS 12.5.7 / Safari)** y optimizada para la resolución 4:3 (`1024×768`).

## ✨ Características

- **Reloj y Fecha Gigante:** Tipografía de alto contraste visible a distancia, con saludo dinámico según la hora del día.
- **Clima en Tiempo Real (Temuco, Chile):** Temperatura actual, sensación térmica, humedad, viento y pronóstico de 3 días usando [Open-Meteo](https://open-meteo.com/).
- **Radios Chilenas en Vivo:** Reproductor HTML5 directo por Bluetooth con **Radio ADN**, **Radio Bío-Bío**, **Radio Futuro** y **Rock & Pop**.
- **Smart Connect (Control Remoto):** Controla las radios y los paneles del hogar desde cualquier celular o computador en tiempo real mediante código QR (estilo Spotify Connect, usando `ntfy.sh` SSE).
- **Hogar Inteligente:** Tarjetas interactivas preparadas para futuras integraciones domóticas.

## 🚀 Uso en el iPad Mini 2

1. Abre Safari en el iPad e ingresa a la URL publicada en GitHub Pages:
   `https://jifacorp.github.io/ipad-mini-smart-wall/`
2. Toca **Compartir** → **Agregar a pantalla de inicio** para abrirlo a pantalla completa sin barras de navegación.
3. En **Ajustes → Pantalla y brillo → Bloqueo automático**, selecciona **Nunca** para mantenerlo encendido en la pared.

## 💻 Desarrollo local

```bash
./iniciar_servidor.sh
```
